## 02 / SELECTED PROJECTS

<p align="center"><a href="https://github.com/MohammedAbusafieh/MalwareX"><img src="./assets/project-malwarex.svg" width="100%" alt="MalwareX — malware analysis and threat detection platform"/></a></p>
**MalwareX** — Python and Streamlit platform for malware analysis, including YARA scanning, VirusTotal lookups, PE analysis, SHA-256 hashing, IOC extraction, and risk assessment.

<p align="center"><a href="https://github.com/MohammedAbusafieh/NetGuard-Pro"><img src="./assets/project-netguard.svg" width="100%" alt="NetGuard Pro — network scanner and risk assessment"/></a></p>
**NetGuard Pro** — Network discovery and security assessment tool using Nmap, with port scanning, service enumeration, topology visualization, risk classification, scan history, and PDF reporting.

<p align="center"><a href="https://github.com/MohammedAbusafieh/DVWA-PenTesting-Lab"><img src="./assets/project-dvwa.svg" width="100%" alt="DVWA penetration testing lab"/></a></p>
**DVWA PenTesting Lab** — Controlled web application security lab covering SQL injection, XSS, command injection, LFI, file upload weaknesses, and access-control issues.

<p align="center"><a href="https://github.com/MohammedAbusafieh/PenTesting-Lab"><img src="./assets/project-pentest.svg" width="100%" alt="Network and system penetration testing lab"/></a></p>
**Network & System PenTesting Lab** — Reconnaissance, enumeration, vulnerability assessment, exploitation, documentation, and remediation practice in a controlled lab environment.

<p align="center"><a href="https://github.com/MohammedAbusafieh/Enterprise-Wireless-Network-Security"><img src="./assets/project-wireless.svg" width="100%" alt="Enterprise wireless network security design"/></a></p>
**Enterprise Wireless Network Security** — Cisco Packet Tracer design featuring WPA2-AES, wireless LAN controller, RADIUS/AAA authentication, DHCP, and secure network segmentation.
